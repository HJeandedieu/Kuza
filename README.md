# Kuza

Kuza is a farming assistant being developed by Team Epals. It helps maize farmers decide when to water, when to apply fertilizer through irrigation, and what to do next. It uses crop stage, weather, field observations, and optional sensor readings to explain its advice. Farmers can also submit plant photos to check for possible problems.

## Current focus

For the 20 November pitch, the team plans to show a software prototype that gives irrigation and fertigation advice using simulated field and weather data. The next milestone is a working maize demo covering field setup, weekly tasks, plant photo review, and harvest and storage guidance.
