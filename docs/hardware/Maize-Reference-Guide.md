# Kuza Maize Reference Guide

**Owner:** Atete Kabundi Eunice  
**Used by:** Angella for rules and Jean for crop context  
**Status:** Draft for source review

Record the agricultural evidence behind Kuza's maize advice. Each approved entry should give the crop stage or situation, what to observe, the recommended action, where it applies, and the source title, section and link.

| Topic | What Eunice needs to verify | Starting reference |
| --- | --- | --- |
| Growth stages | How to estimate the stage from planting information and which field observations can help check it. | eHinga maize guidance cited in the project materials |
| Water needs | Which crop and field conditions matter when giving irrigation advice. | FAO Paper 56 cited in the project materials |
| Field observations | Which observations or symptoms a farmer can report and when further checking is needed. | Maize crop guidance and locally relevant references to confirm |
| Harvest | Signs that maize is ready and the handling advice Kuza can show. | Maize crop guidance to confirm |
| Storage | Drying, sorting and storage advice suitable for the intended user. | Post-harvest guidance to confirm |

Give each approved entry a stable reference ID so Angella can link it from the [rules guide](../backend/Recommendation-Rules-Guide.md). Mark entries pending until their source and local applicability are checked. The starting references come from the concept note.
